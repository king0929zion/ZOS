# BrowserOS Android UI 原型

这是 BrowserOS Android 版本的 UI 原型设计，使用 HTML/CSS/JavaScript 实现，可以在浏览器中预览和测试界面效果。

## 使用方法

1. **直接在浏览器中打开**
   - 双击 `index.html` 文件
   - 或在浏览器中打开 `index.html`

2. **使用移动设备模拟器（推荐）**
   - 打开 Chrome 浏览器
   - 按 F12 打开开发者工具
   - 点击设备工具栏图标（或按 Ctrl+Shift+M）
   - 选择移动设备（如 iPhone 12 Pro）
   - 刷新页面查看移动端效果

## 功能说明

### 底部工具栏

- **左侧区域**
  - 后退按钮：返回上一页
  - 地址栏：输入网址或搜索关键词，按回车加载

- **中间区域**
  - AI 按钮：点击打开 AI 对话面板

- **右侧区域**
  - 功能菜单按钮：点击打开功能菜单面板

### 功能菜单面板

从底部弹出，占据屏幕下三分之一高度，包含以下功能：

- **历史记录**：查看浏览历史（功能开发中）
- **刷新**：刷新当前页面
- **下载历史**：查看下载记录（功能开发中）
- **桌面模式**：切换桌面/移动端视图
- **添加书签**：将当前页面添加到书签
- **书签**：查看所有书签（功能开发中）
- **返回主页**：返回 Google 首页
- **上一页**：返回上一页
- **设置**：打开设置界面（功能开发中）

### AI 对话面板

从底部弹出，占据屏幕 90% 高度，支持：

- **与 AI 对话**：输入消息与 AI 交流
- **AI 操作网页**：AI 可以理解你的指令并操作网页
  - "打开 https://www.example.com" - AI 会打开指定网址
  - "搜索 天气" - AI 会搜索关键词
  - "刷新" - AI 会刷新页面
  - "后退" - AI 会返回上一页

## 交互说明

### 打开/关闭面板

- 点击 AI 按钮或功能菜单按钮打开对应面板
- 点击关闭按钮（×）或遮罩层关闭面板
- 面板从底部平滑弹出，带有动画效果

### 地址栏使用

- 直接输入网址（如 `www.example.com`）
- 输入搜索关键词（如 `天气`）
- 按回车键加载

### AI 对话

- 在 AI 输入框中输入消息
- 按回车键或点击发送按钮发送消息
- AI 会理解你的意图并执行相应操作

## 设计特点

1. **现代化设计**
   - 使用渐变色彩（AI 按钮）
   - 圆角设计
   - 阴影效果

2. **流畅动画**
   - 面板弹出/收起动画
   - 消息出现动画
   - 按钮点击反馈

3. **响应式布局**
   - 适配不同屏幕尺寸
   - 移动端优化

4. **用户体验**
   - 直观的图标设计
   - 清晰的功能分类
   - 便捷的操作方式

## 技术实现

- **HTML5**：结构
- **CSS3**：样式和动画
- **JavaScript**：交互逻辑

## 注意事项

1. 这是一个原型设计，部分功能（如历史记录、书签）仅显示界面，实际功能需要在 Android 应用中实现
2. AI 回复是模拟的，实际应用中需要调用真实的 AI API
3. WebView 使用 iframe 模拟，实际应用中需要使用 Android WebView
4. 书签和历史记录使用 localStorage 临时存储，实际应用中应使用数据库
